# مشروع بوابة إجتماع أسرة عائلة الحميدان 🌴

بوابة إلكترونية متكاملة وتفاعلية لحساب، تسجيل، وإدارة اشتراكات ومصاريف اجتماع أسرة عائلة الحميدان (لوحة تحكم إدارية سحابية + بوابة زوار متوافقة مع الجوال وسطح المكتب).

---

## ✨ المميزات الرئيسية للمشروع

### 1. صفحة الزائر والتسجيل (`index.html`):
- **حاسبة مالية تفاعلية دقيقة**: لحساب اشتراك كل فئة وفق اللائحة الرسمية لأسرة الحميدان:
  - الأب (150 ريال)
  - الزوجة \ الزوجات (150 ريال)
  - الابن أو الابنة (غير الموظفين والطلاب) (50 ريال)
  - الابن الموظف (غير المتزوج) (150 ريال)
  - الابن الموظف (المتزوج) (300 ريال)
  - البنت المتزوجة من غير عائلة الحميدان (150 ريال)
  - ابن/ابنة البنت المتزوجة من غير الحميدان، وذرية بنات العمة هيلة رحمها الله (50 ريال)
- **تسجيل المشترك برمز مرور (PIN)**: يستطيع رب الأسرة إدخال اسمه ورمز مرور ليتم حفظ بياناته ومتابعة حالة السداد لاحقاً.
- **عرض حالة السداد المباشرة**: تظهر شارة فورية بمجرد تسجيل الأسرة توضح هل تم التحقق والسداد (`تم السداد ✓`) أو (`قيد المراجعة / بانتظار التحويل ⏳`).
- **بيانات التحويل البنكي**: زر نسخ فوري لرقم الآيبان (IBAN) واسم الحساب.
- **مشاركة سريعة عبر واتساب**: رسالة منسقة وجاهزة للإرسال لمنسقي الاجتماع.
- **محاكي Google Pixel 6 الفاخر**: نافذة عند الفتح تتيح للمستخدم التبديل السلس بين:
  - 📱 **عرض الجوال بمحاكي Pixel 6**: بإطار هاتف بيكسل 6 حقيقي، شريط الحالة، ونوتش الكاميرا.
  - 💻 **عرض سطح المكتب الكامل**: تجربة متكاملة على الشاشات العريضة.
  - زر عائم للتبديل الفوري بين العرضين في أي لحظة.

---

### 2. لوحة تحكم إدارة الاجتماع والأدمن (`admin.html`):
- **حماية برمز مرور مخصص**: (الرمز الافتراضي: `1448`).
- **لوحة مؤشرات مالية مباشرة (Real-time Dashboard)**:
  - إجمالي الأسر المسجلة
  - إجمالي الحضور (الأفراد)
  - إجمالي الاشتراكات المطلوبة
  - المبالغ المحصلة (تم سدادها)
  - المبالغ المتبقية قيد الانتظار
  - نسبة التحصيل المئوية %
  - إجمالي المصاريف المعتمدة
  - صافي الرصيد المتبقي للصندوق (المحصل - المصاريف)
- **متابعة واعتماد السداد بضغطة زر واحدة**: التبديل الفوري لحالة كل أسرة بين `تم السداد ✓` و `قيد الانتظار ⏳`.
- **نافذة تفاصيل الأسرة**: استعراض أعداد وتفاصيل كل فئة من أفراد الأسرة.
- **مراسلة واتساب فورية**: زر مراسلة مباشر مع كل رب أسرة بنص شكر واعتماد السداد أو تذكير بالتحويل.
- **إدارة مصاريف الاجتماع**: إضافة مصاريف القاعة، الضيافة، العشاء، الجوائز وحساب الأثر المالي فوراً.
- **تصدير وطباعة**:
  - تصدير كشف كامل بملف **Excel (CSV)** يدعم اللغة العربية بترميز UTF-8 BOM.
  - طباعة تقرير رسمي أنيق للملتقى.
- **تعديل الإعدادات وموعد الاجتماع والمقر**:
  - تغيير **تاريخ الاجتماع الجديد** مباشرة.
  - تغيير **اسم القاعة والمقر** ورابط **موقع قوقل ماب (Google Maps)** ليتم تحديثها فورياً في صفحة الزائر ورسائل الواتساب.
  - تغيير **رقم الآيبان (IBAN)** واسم البنك ورمز مرور الأدمن.

## 🚀 طريقة الرفع على GitHub و GitHub Pages

1. افتح مجلد المشروع في الـ Terminal أو Git Bash.
2. قم بتهيئة مستودع جديد ورفع الملفات:
   ```bash
   git init
   git add .
   git commit -m "إطلاق بوابة إجتماع أسرة عائلة الحميدان ١٤٤٨هـ"
   git branch -M main
   git remote add origin https://github.com/USERNAME/REPO_NAME.git
   git push -u origin main
   ```
3. لتفعيل الموقع مجاناً عبر **GitHub Pages**:
   - اذهب إلى مستودع المشروع في موقع GitHub.
   - ادخل على **Settings** > ثم من القائمة الجانبية اختر **Pages**.
   - تحت قسم **Build and deployment**:
     - اختر **Source**: `Deploy from a branch`.
     - اختر الفرع: `main` والمجلد `/ (root)`.
     - اضغط على **Save**.
4. سيظهر لك رابط الموقع المباشر فوراً لمشاركته مع العائلة!
   - رابط الزائر: `https://USERNAME.github.io/REPO_NAME/`
   - رابط الأدمن: `https://USERNAME.github.io/REPO_NAME/admin.html`
